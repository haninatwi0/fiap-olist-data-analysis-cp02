# 🛒 Análise de Dados de E-commerce — Checkpoint 02

Projeto acadêmico desenvolvido na disciplina de **Data Science and Analytics** da FIAP.

A atividade utiliza o **Brazilian E-Commerce Public Dataset by Olist** para realizar uma análise de dados com Pandas, combinando informações presentes em diferentes arquivos `.csv` e respondendo perguntas relacionadas ao negócio.

## 🛠️ Tecnologias

- Python
- Jupyter Notebook
- Pandas
- NumPy

## 📌 Conteúdo

O projeto apresenta:

- exploração e preparação dos dados;
- manipulação de diferentes arquivos `.csv`;
- combinação de datasets;
- análise dos dados com Pandas;
- respostas às perguntas propostas;
- visualizações e interpretação dos resultados;
- sumário executivo de resultados selecionados.

## 📊 Dataset

**Olist Brazilian E-Commerce Public Dataset**

Fonte: [Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

Os arquivos originais do dataset não estão incluídos neste repositório devido ao tamanho. Eles podem ser obtidos diretamente na fonte indicada acima.
